# 数智会计与舞弊穿透智能体技能 (AuditMind)

## 技能概述
依托《中国注册会计师审计准则》第1141号（财务报表审计中与舞弊相关的责任）及《企业会计准则第14号——收入》（CAS 14），对业财数据进行深度穿透分析。

## 核心算法工具与命令
1. **Beneish M-Score 8变量模型**：
   - 变量包括：DSRI (应收账款指数), GMI (毛利率指数), AQI (资产质量指数), SGI (营业收入增长率), DEPI (折旧率指数), SGAI (销售管理费用指数), LVGI (财务杠杆指数), TATA (总应计利润比率)。
   - 临界值：$M > -1.78$ 即为财务操纵高危预警。

2. **三单穿透勾稽比对**：
   - 检查凭证金额与发票、合同、银行流水的一致性；
   - 识别跨期提前确认收入、存货在途虚假采购、关联方隐蔽资金闭环。

3. **本地工具调用**：
   可在终端直接运行 `node dsh-plugin-accounting-audit/test.js` 或 Python 审计算子进行精确计算。
