## 🎯 参赛主线与系统定位 (Core Mission)

本项目紧扣竞赛核心主赛道——**「注册会计师审计、数智审计与舞弊穿透 (AuditMind)」**，严格遵循《中国注册会计师审计准则第1141号——财务报表审计中与舞弊相关的责任》(CSA 1141) 与《企业会计准则》(CAS 14、CAS 1、CAS 36)，针对资本市场“跨期时序倒挂”、“伪造单据与虚增存款”及“体外资金自循环”等新型高隐蔽舞弊，打造从异构业财数据解析到穿透式审计底稿生成的完整工程闭环：

```
[企业财务总账 / Excel记账凭证 / 增值税发票清单 / 银行流水明细]
                           │
                           ▼
[确定性审计算子矩阵] ──► 借贷试算平衡、三单时序倒挂比对、Beneish M-Score 8因子操纵指数
                           │ (注入只读客观事实切片，100% 精确数学运算，根除大模型计算幻觉)
                           ▼
[DeepSeek 准则研判] ──► 对齐 CAS 14(新收入)、CAS 1(存货)、CAS 36(关联方)、CSA 1141 准则深度定性
                           │
                           ▼
[机构级数智全景审计舱] ─► 彭博风格暗曜石工作台（经典案例直达、7分钟答辩看点、SVG交互式资金拓扑回路）
                           │
                           ▼
[结构化合规底稿一键导出] ─► Excel 标准工作底稿 (.xlsx，含审定表、调整分录及CPA终审签章)、PDF穿透分析报告、全量JSON
```

### 数据来源与外部盲测（v2.2）

**财务数据换成年报原值。** 28 例中 23 家舞弊公司的两期财务数据（营收、成本、净利润、应收、存货、流动资产、固定资产、负债、经营现金流、销售/管理费用、折旧）逐项摘自巨潮资讯上**当年原始发布版**年报 PDF（不用事后追溯调整的数据库口径，因为舞弊识别要看的正是当时对外披露的数字）；茅台、福耀、中国移动三家合规公司取 2024/2023 年报披露数。每条数据带 `source_url`（年报 PDF）与 `source_note`（版本、页码、口径），驾驶舱可一键打开年报原文。瑞幸（无 A 股年报）与胜通（债券发行人）仍为结构化重构，并在结果中标注。顺带修正两处证券代码：辅仁药业 600781、金正大 002470。

**Beneish 在真实年报上的表现**（不调参、不看标签）：23 家舞弊公司检出 **13 家（57%）**，3 家合规公司误报 **0 家**。这与文献中 M-Score 的检出率区间一致——它是初筛工具，不是判决。雏鹰农牧 2018 年毛利率为负，GMI 失去经济含义，原实现会算出 M=102908，现按中性值处理并标注。

**外部盲测一：处罚案例留出集**（`data/cases/blind/`）。由一个**看不到本项目任何代码与规则**的独立出题方，依据证监会/地方证监局处罚决定书原文编写 10 家舞弊公司（泽达易盛、紫晶存储、豫金刚石、锦州港、美尚生态、柏堡龙、易见股份、凯乐科技、荣联科技、罗普特，均不在开发集中）+ 4 家合规对照（海天、长江电力、伊利、美的）。运行时剥离处罚摘要、案件类别、文号和真值，按**证据锚点**评分（发现项引用了应识别的单据号即命中，与措辞无关）。

| 模式 | 舞弊公司被标出 | 真值条目命中 | 金额误差≤1% | 合规组出现 HIGH 级误报 | 合规组出现任何 MEDIUM+ 关注项 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 离线确定性（MOCK） | 9/10 | 17/19 | 1/19 | 0/4 | 0/4 |
| DeepSeek 在线（deepseek-flash） | 10/10 | 18/19 | 5/19 | 1/4 | 4/4 |

盲测暴露并已修复的两个真实缺陷：① 复合凭证（收入确认与成本结转写在同一张凭证）被误报"凭证与合同金额不符"；② 以银行回单为原始单据的收付款凭证被误报"引用单据不存在"。修复前合规组 4/4 全部被误报，修复后离线模式 0/4。未修复的问题如实保留：在线模式对合规公司仍倾向列出 MEDIUM 级"关注事项"（海天广告费无合同一项被评为 HIGH），金额精确复核率低——为避免对留出集过拟合，这些不在本集上调参，需用新一批盲测案例校准。

**外部盲测二：合成随机账套**（`src/benchmark/blind_synthetic.py`）。生成器不导入任何检测代码，节假日按国办全部放假通知（含清明、劳动节、端午、中秋与调休上班日）独立生成；每个账套随机注入正例，并放入"近似但不该报"的负例（调休上班的周末记账、有发票的现销、60 天后才回款或只回款 60% 的资金往来）。20 个种子首次运行发现：检测器只内置了三大节日、且不认调休，导致非工作日规则 Precision 仅 0.22、负例误报率 100%。改用 `chinesecalendar`（国办历年通知）后，6 类规则 Recall/Precision 均为 1.00，Benford 区分"自然金额/编造金额"账套准确率 97.5%。

复现：`uv run python -m src.benchmark.blind_synthetic --seeds 20`；`uv run python -m src.benchmark.blind_real --mode mock`（在线加 `--mode online`）。两项已加入 CI。

> **仍需说明的局限**：盲测案例的凭证、流水仍是出题方依据决定书事实重构的结构化账套，不是企业真实账簿；合成账套的异常形态由生成器定义，满分只说明规则按设计工作，不代表真实世界召回率；开发集 28/28 通过仍属"自建自测"，对外请以盲测数字为准。

## 🚀 机构级前端与界面重塑 (Anti-AI-Slop Refinement)

针对传统 AI 生成原型存在的“浮夸霓虹、玩具 Emoji 堆砌、卡片过度嵌套”等廉价感，系统全面吸收了 GitHub 高星反 AI 模板规范（`enterprise-frontend-design`、`ux-skill` 以及彭博/FactSet 机构终端标准），完成专业金融级重塑：

1. **暗曜石金融终端底色 (Obsidian Slate Palette)**：
   - 彻底摒弃 Web3 风格的刺眼荧光青与大面积紫蓝渐变，采用沉稳内敛的 `#0B0F19` 深邃基底与 `#111827` 容器面板，辅以克制的 1px 微分界线；
   - 状态标识遵循严肃法理语义：警示采用正统法理深红，合规采用稳健暗翠绿，主动作采用纯净标准蓝。
2. **去 Emoji 化与证券代码直通车 (Securities Code Presets)**：
   - 剔除所有卡通表情，重构为证券级代码药丸标识：
     - `[600518] 康美药业`（虚增货币 300 亿 / 伪造银行存单）
     - `[002450] 康得新`（虚增存款 122 亿 / 联动池闭环）
     - `[600781] 辅仁药业`（非经营性占用 / 违规担保）
     - `[002069] 獐子岛`（底播存货异常核销 / 异常灭失）
     - `[600660] 福耀玻璃`（真实资本市场合规对照 · 零误报）
3. **原生矢量 SVG 交互式资金拓扑网络 (SVG Topology Matrix)**：
   - 采用自适应矢量 SVG 替代脆弱的 Canvas，**彻底根治 Canvas 在分辨率变化或标签切换时宽度坍缩为 0 的行业通病**；
   - 动态虚线流动回路清晰勾勒资金划出、虚假账户、实控人过桥、虚假购销至资金回流的自闭环；
   - 正下方常驻**五步资金链路穿透明细表**，支持远距离投影仪汇报时评委一目了然。
4. **注会实务工作备忘录排版 (Audit Memorandum)**：
   - 发现项按实务规范自动编制编号（`RF-01`, `RF-02`），分层严谨列示【客观事实证据】、【依据准则条款】及【建议审计程序】，并配备一键复制证据链工具。

## ⚡ 极速启动与运行指南

### 方式一：Windows 一键双击极速启动（比赛现场推荐）
直接双击根目录下的 **`run.bat`**，系统将自动自检依赖、单端口（8501）全量托管 FastAPI 后端与 React 18 SPA，并在默认浏览器直接打开：
👉 `http://localhost:8501`

### 方式二：命令行启动
```bash
# 1. 克隆项目与同步环境
git clone https://github.com/zhutmg00-eng/accounting-agent-0438.git
cd accounting-agent-0438
uv sync   # 或 pip install -e .

# 2. 启动单端口整合服务 (FastAPI + SPA 统一托管)
uv run python main.py

# 3. 运行自动化评测基准套件 (28 案例全量评分卡)
uv run python src/benchmark/benchmark_runner.py

# 4. 运行全量自动化测试套件（60 项）
uv run pytest -v
```
