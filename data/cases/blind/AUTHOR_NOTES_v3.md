## 2. 哪些是真实的，哪些是构造的

**决定书事实（手法、认定金额、文号）**：都取自下面的页面，出题人逐页打开过：
- 证监会官网全文：华锐风电、山东墨龙、紫鑫药业、荃银高科（安徽局）。
- 乐视网：用 curl 抓取证监会官网页面，只检索了“框架合同 / 互换 / 担保”相关段落。
- 广东榕泰、亚联发展、沈阳化工：没有打开证监局原页面，用的是公司公告（证券日报电子版 / 新浪 PDF）中全文转载的决定书内容。
- 中天能源：北京局原页面没有抓到（返回空页），事实来自证监会行政复议决定书〔2023〕78号对处罚决定〔2022〕16号的转述。文号来自另一份复议决定的搜索摘要，原决定书全文**未核验**。
- 园城黄金：证监局原页面没有打开全文。事实来自搜索摘要（山东局页面摘要，以及上交所纪律处分、新闻转载），多处摘要内容一致。

**直接沿用决定书原数的 expected_amount（与认定金额一致）**：
- 华锐风电不是（见下文“按比例构造”）。
- 乐视：鼎诚文众 2,547.17万、博思百川 2,641.51万（按 6% 税率反推得到 25,471,698.11 / 26,415,094.34）；高钧互换虚减成本 943.40万。
- 榕泰：虚构回款 3,124.23万。保理利息合计 11,779,902.92，与决定书 1,177.99万差 0.01，原因是拆成两笔时有四舍五入。
- 紫鑫：新银润销售收入 2 亿元；销售成本 104,994,815.92 是用 2 亿减去决定书认定的利润 95,005,184.08 反推出来的。
- 园城：钢材贸易收入 6,495.18万；绩效奖金 40.13万。
- 亚联：8,278,844.67 和 13,714,256.57。
- 荃银：18,715,068.36。
- 中天能源：追偿款挂账 6,400万，等于少计提 0.64亿；预付 2.64亿。

**按比例构造的金额（非决定书原数）**：
- 华锐：两笔提前确认合计 2.64 亿元（决定书总额 24.32 亿元）。
- 墨龙：暂估收入 6,000万、冲减成本 4,750万。
- 榕泰：关联采购 4,345万。决定书全年为 40,376.68万。
- 紫鑫：存货虚增 7.3425 亿，约为决定书 14.685 亿的 50%；预付嘉益人参 1.5 亿，完全是构造数。
- 沈阳化工：约为决定书 2018 年数的 1/10。

**构造的分录形式与日期（不是决定书描述）**：
- 中天能源 ZT-V07：现实中公司只按 20% 计提了预计负债。为了让少计金额能从凭证里直接加总出来，出题人改写成“借 6711 1,600万 + 借 1221 6,400万 / 贷 2801 8,000万”。这样对利润的影响与现实一致，但资产负债表的列示是构造的。
- 中天能源 ZT-V03 / V05：决定书只说青岛中天向九头风付了 2.64 亿元，没有付款日期。两笔付款的日期（2020年3月、7月）和拆分金额都是构造的；决定书称业务自 2018 年下半年起已停滞。
- 紫鑫 ZX-V10：决定书认定的是“向关联公司支付采购款、资金未付给出售方”。收款方延边嘉益人参贸易有限责任公司在决定书中出现，但出现在关联担保部分，并没有写它收过采购款。
- 亚联：决定书说这两项是“会计处理不当”（错误清理应付、重复冲减），没有写有主观故意。
- 荃银：决定书只说“未单项计提”。出题人用该客户应收余额（种子免税，含税等于不含税）作为真值金额，正好等于决定书的少计提额。
- 沈阳化工 SH-V07 的科目搭配是构造的：决定书写的是“虚减成本、虚增预付、虚减存货/应付”，出题人用“借预付 / 贷成本”来体现。
- 园城 YC-V06：现实中公司是“未入账”，出题人改成“冲回已计提”的形式，好让这笔金额能落在凭证上。

**税率**按期间设定：2011 和 2015–2016 年 17% / 6%；2018 年 17% / 16%；2019 年 16% / 13%；之后 13% / 9% / 6%。种子和林下参按免税处理，出口按零税率。榕泰保理利息用 3%，这是出题人的设定，没有核实适用税率。

**交易对手**：决定书中点名的公司（鼎诚文众、博思百川、上海高钧、和通塑胶、永佳农资、中粤农资、新银润、九头风、嘉益人参、广州农商行、鸿展等）和自然人（王某丽、马某祥）用的是原名或决定书里的匿名写法。其余客户、供应商（例如“上海鑫驰汽车”“甘肃安北风力发电”“贵州黔禾农业”“辽宁润宏石化”“天津荣钢物资”）都是虚构的。少数真实机构只作为正常业务对手出现（供电公司、中国银联、青岛市慈善总会、三一集团有限公司等），这些交易本身都是构造的。

**其他**：发票号、银行账号尾号、经办人姓名、所有凭证编号全部虚构；银行流水的期初余额是设定值。

## 3. 合规公司：未核验的事项

- “近年无财务造假处罚”是出题人凭自己的知识判断的，**没有逐家检索证监会处罚库核验**。
- source_url 用的是公司官网首页，**没有打开核验，也不是年报链接**。
- 所有凭证都是构造的，金额不代表公司真实数据。
- 三一重工与三一集团有限公司之间的“工业互联网平台服务”关联交易是构造的，只用来体现“已审议、已披露的关联交易”这一特征；交易内容未核验。
- “看似异常、实际正常”的特征（每家至少 2 种）：
  - 五粮液：跨年预收、整数广告费 3,000万、票据背书、周末收款、国庆付款、年末计提市场支持费 1.86亿。
  - 青岛啤酒：整数公益捐赠 200万、劳动节付款、整数赞助费 1,000万、月末复合凭证、年终奖计提 1.05亿。
  - 迈瑞医疗：跨年预收、年终奖大额计提 5亿、周末付款、票据背书。
  - 三一重工：首付加分期的复合销售凭证、质量保证金大额计提 3.2亿、已披露关联交易、国庆及周末付款、整数展会费 500万。
  - 顺丰控股：春节付款、整数广告费 2,000万、跨年预存运费、复合收入凭证、年末暂估航油 1.68亿。
  - 立讯精密：存货跌价大额计提 2.65亿、票据背书、周末付款、出口零税率、复合凭证。

## 4. 已知局限

- 为满足“金额能由指定科目、指定方向精确加总”的要求，有几条真值的金额口径是“问题分录或问题余额的金额”，不等于报表错报额：
  - 中天能源 F2：预付 2.64 亿，决定书认定应计提 1.32 亿。
  - 荃银：用应收余额作口径，这一条恰好等于少计提额。
  
  每条的口径都在 amount_basis 中写明了。
- 部分凭证摘要带有中性的业务线索，例如“第三方代付”“暂估”“冲回”“清理三年以上应付”，没有用禁用词。
- 华锐风电（2011）、乐视网（2015）、山东墨龙（2016）都发生在旧《证券法》时期，standard_clause 引用的是 2005 年《证券法》条款，按适用法律选取。
